# Changelog

## 0.1.0

First release.

- Remote MCP server with one AliExpress (速卖通) tool for product search, product links and whole stores: prices, exact order counts, ratings, variants with stock, seller details, shipping for 63 delivery markets and optional buyer reviews.
- Apify sign-in (OAuth) for Claude, ChatGPT, Cursor, VS Code, Codex and other remote MCP clients; token header as an alternative.
- Claude Code plugin with the AliExpress skill: run flow for longer requests, input recipes per job, market settings and field sets.
- Client configuration examples, code examples for Python, JavaScript and HTTP, and an MCP Registry manifest.
